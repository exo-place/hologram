# docs/reference/

Full reference documentation for Hologram's fact language, template system, expressions, and slash commands.

## Files

- `facts.md` — Fact syntax, directives (`$respond`, `$model`, `$if`, `$stream`, etc.), and patterns
- `templates.md` — Nunjucks template reference: variables, `send_as` macro, template inheritance
- `expressions.md` — `$if` expression syntax, operators, and available variables
- `tools.md` — LLM tool call reference (`add_fact`, `update_fact`, `remove_fact`)
- `configuration.md` — Entity config options and their effects
- `commands.md` — All slash commands with options and permission requirements
